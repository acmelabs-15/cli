# @acmelabs/cli

`@acmelabs/cli` is `acmelabs`, the one tool for ACMElabs repos. It makes a new repo start in the ACMElabs shape and keeps every repo in that shape afterwards.

**Status:** in development. The package is not on npm yet, so there is nothing to install. The first module, `repo-model`, is being built.

The commands, the status of the work and the project's records are in the [repo's README](https://github.com/acmelabs-15/cli#readme).
